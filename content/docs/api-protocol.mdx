---
title: API 与协议
description: ANI SDK 和 adapter 应以协议快照为准。
---

ANI 后端维护一组协议契约文件，供 SDK、adapter 和 extension 跟随后端演进。

## 权威文件

```text
dev/agent-native-im/docs/protocol/
  openapi.yaml
  ws-events.schema.json
  manifest.json
  routes.generated.json
```

其中：

- `openapi.yaml`: REST API 快照。
- `ws-events.schema.json`: WebSocket 事件结构。
- `manifest.json`: SDK 必须覆盖的核心路径、字段和事件。
- `routes.generated.json`: 从后端路由生成的 `/api/v1` 路由清单。

## 后端维护命令

```bash
make protocol-generate
make protocol-check
```

## SDK 同步方向

Python SDK 和 JavaScript SDK 应拉取 `docs/protocol` 中的契约文件，生成或检查自身接口覆盖范围。这样后端新增关键字段时，SDK 更容易发现偏差。
